# PopFE GUI

A GUI front end for pop-fe, the PlayStation 1 disc-image converter — build PS1 game packages for PSP, PS3, and PS Vita formats from your own disc images, with a persistent queue and session log.

## Credits

- **pop-fe** — created by **sahlberg** (github.com/sahlberg/pop-fe). All conversion logic is pop-fe's; this project only wraps it in a desktop GUI.
- Disc images are the user's own; no game data is included or distributed.
